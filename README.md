# Tecnicas-de-programacao-1

## Aulas de Técnica de Programação 1

Este Repositório reúne os conteúdos, exercícios e atividades desenvolvidos durante a disciplina de Técnicas de Programação no IFSP - Campus Boituva, ao longo de 2026.

O objetivo desse projeto é documentar minha evolução acadêmica e prática, registrando os conceitos e boas práticas aprendidas durante as aulas.

Além de servir como material de consulta e revisão, este repositório demonstra meu comprometimento com o aprendizado contínuo, organização de projetos e o desenvolvimento de competências na área de tecnologia.

Durante a disciplina será desenvolvido, de maneira incremental, uma aplicação de loja de produtos.

## Observação

O repositório tem caráter acadêmico e reúne anotações, exercícios, atividades práticas e exemplos desenvolvidos em aula. Alguns códigos podem estar incompletos ou sujeitos a melhorias futuras.
